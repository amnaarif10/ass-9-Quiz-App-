## 📐 Overview & Layout Architecture

This project features a seamless single-page application (SPA) flow with card-style containers and grid aesthetic styling:

| Screen / View | Key Features & Functionality |
| :--- | :--- |
| **Welcome Screen** | Title heading, quiz guidelines, and a "Start Quiz" trigger button |
| **Quiz Canvas** | Dynamic question counter, interactive option choices, answer verification state (green/red), and next action controls |
| **Result Screen** | Score tally, dynamic feedback performance message, and a "Play Again" restart button |

---

## ✨ Features

* 🎯 **Instant Feedback:** Interactive answer validation with instant visual highlighting (Green for correct, Red for wrong).
* 🔒 **Selection Locking:** Options are automatically disabled once an answer is selected to prevent double-guessing.
* 📊 **Smart Score System:** Evaluates total score and generates customized feedback messages based on performance tiers.
* 🎨 **Scrapbook Grid Aesthetic:** Built with custom SVG grid patterns, floating decorative emojis, and subtle drop shadows.
